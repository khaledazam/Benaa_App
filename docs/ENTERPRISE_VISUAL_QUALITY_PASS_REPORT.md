## 3. التحقق البصري الميداني ولقطات الشاشات الملتقطة

تم اختبار النظام واجهة حية عبر متصفح Chrome Web وFlutter Engine بدقة متناهية:

### أ. لوحة المعلومات (Dashboard Screen)
1. **اللوحة ممتلئة بالبيانات الحية (Populated Dashboard):**
   * بطاقة السياق: مستودع مواد البناء والديكور الرئيسي (WH-01) مع مؤشر النبض الأخضر `متصل سحابياً (MongoDB Sync)`.
   * شبكة مؤشرات الأداء 2×2: إجمالي الأصناف (32 صنفاً)، شحنات قادمة (سند واحد بانتظار الفحص)، قيمة المخزون (425,800 ر.س)، وشيك النفاذ (3 أصناف حرجة).
   * شريط نسبة توفر الأصناف بالمستودع بنسبة 91% مع مؤشر خطي سلس.
   * بطاقات العمليات الرئيسية ذات الأولوية العالية مع أزرار الانتقال الفوري.
   * قائمة أحدث سندات الشحن بين الفروع (من الرياض، عنيزة، جدة).
2. **اللوحة بحالة الفراغ (Empty State Dashboard):**
   * مؤشرات 0 صنف و0 شحنات مع رسائل إرشادية وأزرار مباشرة لإنشاء أول سند شحن أو إضافة أول صنف بدون أي تشويه بصري أو مساحات ميتة.

### ب. شاشة سجل المخزون والأصناف (Inventory with 32 Real Products)
* تم تجهيز المستودع الافتراضي بـ **32 صنفاً واقعياً ومطابقاً لأسواق البناء والديكور بالمملكة**:
  * ألواح جبس بورد كناوف (عادي، مقاوم للرطوبة، مقاوم للحريق).
  * قطاعات حديد مجلفنة (أوميجا 0.45 مم، C-Stud 70 مم، U-Track 70 مم).
  * معجون فواصل كناوف 28 كجم، شريط فايبر جلاس، شريط ورقي مثقب.
  * براغي جبس 25 مم، براغي حديد ذاتية الثقب 35 مم، فيشر إسفين حديد 6 مم.
  * بلاطات أسقف جبسية فينيل 60×60، وبلاطات ألياف صخرية عازلة للصوت.
  * عوازل صوف صخري 50 كجم، صوف زجاجي مع قصدير ألومنيوم.
  * دهانات جوتن بروفيشنال وسيلر أساس مائي وسيليكون فواصل.
  * كشافات ليد بانل 60×60 وسبوت لايت مانع للتوهج وإضاءة شريطية مخفية.
* شريط فلاتر التصنيفات بالتمرير الأفقي السلس (`الكل`، `ألواح جبسية`، `قطاعات حديد`، `دهانات وعوازل`، إلخ).
* بطاقات الأصناف `ProductListTile` تعرض بوضوح فائق: أيقونة الصنف، الكود SKU، موضع الرف (`ممر A - رف 1`)، وسام حالة التوفر، والرصيد الفعلي بالأرقام الجدولية البارزة والوحدة.

### ج. شاشة تفاصيل وخيارات الصنف (Item Bottom Sheet Details)
* ورقة خيارات منبثقة ناعمة عند النقر على أي صنف تتيح: تعديل الرصيد الفعلي، فتح كارت الصنف وسجل الحركات، طباعة ملصق الباركود الحراري، وحذف الصنف مع حوار التأكيد المؤسسي.

### د. شاشات العمليات وسندات التحويل والمبيعات (Operations & Sales)
* استلام وتدقيق سندات التحويل الواردة من الرياض وجدة وعنيزة.
* صرف مبيعات وسندات تسليم العملاء.
* كشوف حساب العملاء (مؤسسة إعمار نجد، شركة أفق الديكور، مجموعة المهيدب).

### هـ. بوابة الإدارة العليا والمستخدمين (Super Admin Screen)
* بطاقة إحصائيات الحسابات النشطة والموقوفة.
* إنشاء وتعيين أدوار المستخدمين (أمين مستودع، مشرف تدقيق، مدير مبيعات، سوبر أدمن).
* الحفاظ الكامل على ربط سحابة MongoDB وخدمة المصادقة الموحدة `CloudAuthService`.
